# AnimeBT 资源检索审计

审计日期为 2026 年 11 月 10 日。涵盖 GUI 的 11 个来源：八个基础来源和三个扩展来源。在线探测只请求公开索引及元数据，离线回放以固定响应衡量采集和归属。

## 11 个来源

在线对照用「名侦探柯南」探测接口行为，不作为作品归属或站点资源总量的统计。计数为当次请求收到的记录，包含分页和镜像重复。

## 搜索流水线

1. GUI 将 Bangumi 正式名称、已记录别名和作品关系组织为有预算的检索计划。保留原文，轮换中文、繁体、日文、英文和明确标记的罗马音。分离并列语言名，按通用规则加入季度别名、区分性副标题、章节名及足够长的缩写。扩展词只用于发现候选。
2. 请求层记录实际 HTTP 方法、路径、参数、页数和错误。常规模式最多 7 个查询词，每个分页接口最多 6 页，来源时间预算为 28 秒。已有的「重新搜索」入口运行深度模式，跳过缓存，最多 12 个词和 12 页，来源时间预算为 60 秒。单个请求仍受原有来源超时和专用窗口约束。
3. 单次检索同时最多 12 个来源 HTTP 请求，每个来源最多 2 个。各来源有独立任务，HTTP 429 读取 `Retry-After` 后进入冷却。成功页增量返回，后续超时或分类失败保留已取得的候选。取消会停止分页及别名任务，GUI 的搜索代次控制继续隔离旧结果。
4. 标准化后保留原始标题、来源、查询词、站点 ID 和真实链接。GUI 采集阶段不再要求标题同时出现请求里的所有词。候选仍要经过原有的严格作品归属验证。Info Hash 冲突不会合并，镜像证据矛盾时不会确认，去重结果保留来源和查询来源记录。
5. GUI 详情页会继续查所有启用来源，找到一条资源不会结束其他来源或其别名查询。海报预检仍只验证资源存在性，有严格证据及可用链接就能显示海报，详情页再进行完整检索。
6. 新缓存区分 GUI 的关键词列表模式、候选模式和分页预算。空结果及受范围限制的缓存最多有效 45 秒，失败或超时响应不保存为成功缓存。并发写入使用独立临时文件再替换。
7. `%LOCALAPPDATA%\AnimeBT\logs\animebt.log` 记录请求、原始与标准化数量、归属通过及拒绝理由、镜像冲突、去重数量和终态。来源详情可区分返回零条、有限范围、归属未确认、未完成与失败。站点只返回近期 RSS 或查询被截断时，无法据此确认站点全站没有资源。

## 可复现对照

用 [检索回放测试](../tests/test_retrieval_pipeline.py) 将同一批标题样本和模拟 HTTP 响应送入修改前后的代码。涵盖 11 个来源、五个 Bangumi 条目、公开标题样本、假定的独立版本和合集、同系列干扰项。测试中的哈希及 HTTP 响应仅用于模拟。真值按测试清单预先固定，分别计算来源与版本组合的采集覆盖和最终跨源去重后的归属准确度。

| 条目 | 原始候选来源与版本组合 | 有效候选采集 | 最终确认 | 误匹配 | 本机回放耗时，旧版 → 新版 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 尸体派对 Tortured Souls | 30 → 31 | 18 → 21 / 21 | 2 → 2 | 0 → 0 | 281 → 297 ms |
| 咒术回战 第二季 | 30 → 31 | 18 → 21 / 21 | 2 → 2 | 0 → 0 | 171 → 266 ms |
| 进击的巨人 完结篇 THE LAST ATTACK | 21 → 22 | 10 → 12 / 12 | 1 → 2 | 0 → 0 | 63 → 203 ms |
| 进击的巨人 最终季 完结篇 前篇 | 30 → 31 | 18 → 21 / 21 | 2 → 2 | 0 → 0 | 125 → 204 ms |
| 进击的巨人 OAD | 30 → 31 | 18 → 21 / 21 | 2 → 2 | 0 → 0 | 140 → 188 ms |
| 合计 | 141 → 146 | 82 → 96 / 96 | 9 → 10 | 0 → 0 | 780 → 1,158 ms |

在固定清单的 146 个原始来源与版本组合中，旧版请求覆盖 141 个，新版覆盖 146 个。标准化后进入归属层的组合为 96 → 146，包含预期被拒绝的干扰资源。有效候选采集率为 85.4% → 100%，最终漏检率为 10% → 0%，最终输出误匹配率两版均为 0%。请求数为 239 → 453。回放关闭了外站请求间隔，这些毫秒数只代表本机模拟耗时。真实网络会受到来源响应、限流和下载窗口影响。

运行全部测试用 `python -m unittest discover -s tests`。只运行回放用 `python tests/test_retrieval_pipeline.py`，需先安装本项目及 GUI 依赖。已有测试与新增测试共同覆盖跨源哈希冲突、不同季度、OVA、OAD、SP、剧场版、累计集数、明确合集、坏行、窗口截断、缓存过期、部分成功、超时、HTTP 429 及取消。

## 尚未解决的边界

- ACG.RIP 本轮未能在线连通。MioBT 只有已验证的近期 RSS，ACGNX、KissSub、Comicat 和 Tokyo Toshokan 尚未确认可用的历史搜索路径。保留这些来源的能力边界，不绕过验证页、登录和限流。
- 站点未索引、未公开、需登录、已删除或超出网页与 API 窗口的资源无法通过本次检索找到。
- Bangumi 未记录的英文译名、罗马音、俗称和作品关系仍可能漏检。仅在 Torrent 文件内部可证实的合集成员也仍可能无法从公开标题和元数据确认。
- 离线回放展示了特定缺陷得到修复。它没有提供全站召回率、全站误匹配率或长期网络速度的估计。
