# Liquid Glass 连续表面材质验证

本次仅修改本地光学材质及验证代码，未修改搜索、归属、AI 解析、磁链或发布逻辑。

## 根因与修复

旧着色器在阅读底板中央提前返回透明片元，随后由不透明 Rectangle 覆盖中央；颜色硬限幅进一步压平了背景差异。因此只有窄边缘呈现折射。

现在硬件渲染不再绘制中央不透明底板，也不跳过中央采样。整个表面使用真实下层纹理：中央采用弱透镜位移、连续模糊和着色，边缘保留曲面折射、Schlick Fresnel、高光及厚度暗线。阅读区域通过连续亮度映射保护对比度，保留背景变化而非裁成单色。

Control 用于按钮和输入框；Chrome 用于顶栏；Panel 用于弹窗；Card 用于资源阅读区域。卡片采用三次纹理采样，其余普通控件五次，菜单九次；中央跳过不需要的边缘法线和高光计算。菜单设置最低模糊及更窄亮度范围，抑制背景文字；空闲菜单项不重复绘制玻璃底板和边框。

全局透明度、blurStrength、refractionStrength 继续统一驱动材质，现在中央也响应参数变化。未增加新的模糊或折射设置入口。文字、图片、图标保持独立前景，不施加折射或整体透明度。

## 背景采样与限制

复用共享的应用内环境纹理、页面纹理及弹窗下层材质纹理。消费纹理的前景不进入对应捕获，避免递归；不为每张卡片捕获整个窗口。纹理按 DPR 请求并限制在 1600×1000 像素预算内。

这是应用内实时纹理的屏幕空间光学近似，不是对桌面或其他窗口的捕获。Qt Quick 无法直接采样 DWM 最终合成画面；本实现不宣称桌面折射。平滑背景上位移自然较弱；复杂纹理更容易观察。软件渲染继续使用简化材质，不提供实时折射。

## 实际验证

- 100 项回归测试重跑通过。前一次有一项系统剪贴板立即读回为空的失败；未修改业务代码，整套重跑通过。
- D3D11、100% / 150% / 200% DPI 的光学验证通过，无 QML / Shader 警告。
- 同一实时 QML 图案，关闭模糊和高光后，中央折射差异浅色 9.361、深色 7.403；移动背景后阅读中央变化 14.842 / 19.560，边缘变化 79.129 / 62.735。数值为图像通道平均绝对差，证明中央不再静止且边缘响应更强，不代表物理精度。
- 真实 GUI 下拉菜单三个项目的背景采样最低文字对比度：浅色 7.56:1、深色 9.52:1。没有重复焦点边框；有限采样不等于所有动态背景的穷尽证明。
- 1000 条离线资源样本、连续滚动并拖动全局透明度的性能见下表。样本仅用于 UI 压测，不冒充在线搜索结果。

| 场景 | UI 帧/秒 | P95 间隔 | 最长间隔 |
| --- | ---: | ---: | ---: |
| list-light-optical | 90.8 | 17.5 ms | 20.44 ms |
| list-dark-optical | 88.4 | 16.74 ms | 20.28 ms |
| poster-light-optical | 86 | 17.21 ms | 29.17 ms |
| poster-dark-optical | 87.2 | 17.17 ms | 40.53 ms |

数据是 FrameAnimation 墙钟帧间隔，不是 GPU 时间戳或显示器帧率；短时结果受系统调度影响，不能宣称稳定锁定 60FPS。初版连续采样曾降低性能，优化中央计算与卡片采样后恢复；仍存在偶发长帧。
