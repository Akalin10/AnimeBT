## 三步开始

1. 下载 ZIP，解压整个文件夹，双击 `AnimeBT.exe`。无需安装 Python。
2. 输入番名，例如 `Re:Zero`，按 Enter。找到资源的作品会陆续显示海报。
3. 点开海报，按集数、清晰度或字幕组挑选。点击缩略图可复制磁链，右键可保存 Torrent。

## 找番更省事

- **一次查 11 个来源** · 支持用中文、日文和英文片名找资源，列表上能看到每条资源来自哪里。
- **按作品找资源** · 不同季度、OVA 和剧场版分开显示，避免把同系列的其他作品混在一起。
- **界面随你调** · 浅色、深色和四档海报尺寸都在右上角设置，启动动画也可关闭。
